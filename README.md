# 🐦 Pacebird — Programmatic Intelligence

Pacebird is a programmatic advertising analytics platform built for ad tech professionals managing DSP campaigns across DV360, The Trade Desk, and similar platforms. It turns raw CSV exports into structured performance charts, AI-written campaign insights, and client-ready PowerPoint reports — all inside a web-based dashboard with no code required. The platform supports two operating modes: a live API data mode for connected workflows and a file-upload mode for one-off analysis of DSP exports.

## Key Features

### 📊 Performance & Insights

- **Multi-file upload** — accepts CSV, TSV, XLSX, and XLS exports from DV360, The Trade Desk, or any generic DSP format; multiple files can be stacked and analysed together
- **Auto-detection** of DSP source and automatic column normalisation across different naming conventions
- **Summary metrics** — Impressions, Clicks, Spend, CTR, CPM displayed as KPI cards; all metrics recalculated from raw numbers rather than DSP-provided averages
- **KPI RAG status** — per-brand Red/Amber/Green status cards when KPI targets are configured in Settings
- **Interactive charts** — spend by advertiser, CPM by campaign, best/worst line items by CPM, filterable by advertiser and DSP; all rendered with Plotly in white card containers
- **Daily performance chart** — dual-axis time series (configurable left/right metrics) shown when date data is present
- **Period comparison** — WoW, MoM, QoQ, and YoY comparison table with directional status indicators; requires 14+ days of date data
- **AI Advertiser Insights** — per-brand streaming insights covering Display, Video, and YouTube channels with specific metric references; informed by Brand Memory context when available
- **AI-Driven Analysis** — on-demand chart recommendations and dataset summary generated by Claude; includes anomaly detection
- **Natural language querying** — ask plain-English questions about the loaded dataset; answers cite specific numbers from the data
- **Section-picker PPTX export** — "Build Your Report" dialog lets you select which sections to include (Summary Metrics, Performance Charts, Daily Performance, Period Comparison, AI Advertiser Insights, AI-Driven Analysis); generates a dark-theme PowerPoint deck; AI sections reuse cached results where available

### 📋 Portfolio Overview

- Aggregated performance view across all brands from the current data source
- Works in both API Data mode (reading live mock data) and Upload Report mode (reading from uploaded CSV files)
- Brand-level spend, impressions, and CTR breakdowns

### 🎯 Live Campaigns

- **Pacing dashboard** — budget vs spend progress bars per campaign with RAG status (On track / At risk / Critical / Overpacing), percentage elapsed, and recommended daily spend to hit budget
- **Portfolio overview** — aggregate spend, remaining budget, and campaign count
- **Delivery troubleshooter** — interactive diagnostics tool for identifying and resolving common delivery issues (budget caps, frequency, targeting, creative)
- **Campaign performance troubleshooter** — structured troubleshooting workflow for performance issues by campaign type (Display, Video, Search)
- In Upload Report mode: accepts a CSV pacing export and applies the same RAG logic to uploaded data

### 📡 Cross-Channel Dashboard

- Unified view across Google Search, Programmatic (DV360), Meta, Affiliates, and other channels
- Summary metrics and per-channel performance table (Spend, Impressions, CTR, CPA, CPO, Conversions)
- **Spend by channel** bar chart and **CPA/CPO optimisation tracker** comparing actual vs target
- **Performance alerts** — flags channels where CPA exceeds target threshold, with recommended actions
- **AI Performance Insights** — Claude-generated commentary on cross-channel efficiency and budget reallocation opportunities
- PowerPoint export of the cross-channel report

### ⚙️ Settings

Six tabs covering all configuration and context management:

| Tab | Purpose |
|-----|---------|
| 📋 Brand Memory | Store free-text context (objectives, KPIs, notes) per brand; used to personalise AI insights |
| 📧 Email Context | Search Gmail for brand-related emails; save selected emails directly into Brand Memory |
| 🎙 Meeting Transcription | Upload audio/video recordings (mp3, mp4, wav, m4a, webm); transcribed via OpenAI Whisper and saved to Brand Memory |
| 🎯 KPI Targets | Set per-brand targets for CTR, CPM, CPA, and other metrics; drives the RAG status display on Performance & Insights |
| 📬 Scheduled Reports | Configure scheduled report delivery settings |
| 🔔 Alert Settings | Configure thresholds for automated performance alerts |

Brand Memory entries are matched to campaigns using partial, case-insensitive name matching (e.g. a memory key `"Nike"` applies to any campaign containing `"Nike"`).

## Tech Stack

### Framework & UI
- **Python 3.x**
- **Streamlit** — multi-page app framework, session state, dialogs, file upload

### Data
- **pandas** — all data loading, normalisation, aggregation, and analysis
- **openpyxl** — Excel file reading (`.xlsx` / `.xls`)

### Visualisation
- **Plotly** — interactive charts (bar, line, scatter, pie) rendered in the browser
- **Matplotlib** — static chart rendering for PowerPoint slide images

### AI & APIs
- **Anthropic (`claude-sonnet-4-6`)** — AI-generated campaign insights, PPTX slide content, natural language querying, cross-channel analysis
- **OpenAI Whisper (`whisper-1`)** — meeting audio transcription
- **Google Gmail API** — email search and retrieval for brand context
- **sentence-transformers** (`all-MiniLM-L6-v2`) — semantic similarity for email search results

### Export
- **python-pptx** — PowerPoint report generation (built from scratch, no template file)

### Supporting Libraries
- `google-auth`, `google-auth-oauthlib`, `google-auth-httplib2` — Gmail OAuth2
- `scikit-learn` — used with sentence-transformers for similarity scoring
- `pydub` — audio file handling for transcription uploads

## Getting Started

### Prerequisites

- Python 3.9 or later
- pip

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd insights-app

# Install dependencies
pip install -r requirements.txt
```

### API Keys

Create the Streamlit secrets file:

```bash
mkdir -p .streamlit
```

Then create `.streamlit/secrets.toml` with the following structure. **Do not add actual key values to version control.**

```toml
# .streamlit/secrets.toml

ANTHROPIC_API_KEY = "your-anthropic-api-key-here"
OPENAI_API_KEY    = "your-openai-api-key-here"
```

| Key | Required | Used for |
|-----|----------|---------|
| `ANTHROPIC_API_KEY` | Yes (for AI features) | Claude insights, PPTX slide content, NL querying |
| `OPENAI_API_KEY` | Optional | Whisper meeting transcription in Settings |

Both keys are also readable from environment variables if you prefer that approach:

```bash
export ANTHROPIC_API_KEY="your-key"
export OPENAI_API_KEY="your-key"
```

### Gmail Integration (optional)

The Email Context tab in Settings connects to Gmail via OAuth2. To enable it:

1. Create a Google Cloud project and enable the Gmail API
2. Download the OAuth2 credentials as `credentials.json` and place it in the project root
3. On first use, the app will open a browser window to complete authentication; the token is cached in `token.json`

Both `credentials.json` and `token.json` are excluded from version control via `.gitignore`.

> **Note:** Gmail authentication uses a local browser flow and **cannot run on Streamlit Cloud**. Use the Email Context tab locally, save the emails you need to Brand Memory, and deploy with `brand_memory.json` already populated.

### Running Locally

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501` by default.

## Quick Commands

### With `make` (requires installation — see below)

| Command | What it does |
|---------|-------------|
| `make install` | Install dependencies from `requirements.txt` |
| `make run` | Launch the Streamlit app |
| `make dev` | Launch with auto-reload on file save |
| `make clean` | Remove `__pycache__` directories and `.pyc` files |
| `make freeze` | Overwrite `requirements.txt` with the current environment |

### Installing `make` on Windows

`make` is not included with Windows. Install it with one of:

```powershell
# Option 1 — winget (built into Windows 11)
winget install GnuWin32.Make

# Option 2 — Chocolatey (if installed)
choco install make
```

After installation, restart your terminal and `make` will be available.

### PowerShell fallbacks (no `make` required)

If you prefer not to install `make`, equivalent scripts are included:

```powershell
# Run the app
.\run.ps1

# Run in dev mode (auto-reload)
.\dev.ps1

# All other targets via tasks.ps1
.\tasks.ps1 install
.\tasks.ps1 clean
.\tasks.ps1 freeze
```

> **First-time PowerShell setup:** if scripts are blocked by execution policy, run once as Administrator:
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

## Configuration

### Access Tiers (`config.json`)

`config.json` controls which navigation sections are visible. Set `current_tier` to one of the four values:

```json
{
  "current_tier": "full_access"
}
```

| Tier | Sidebar sections visible |
|------|--------------------------|
| `full_access` | 📡 API Data + 📁 Upload Report + 📈 Sell Side + 🎯 Audiences & Deals Pipeline |
| `api_only` | 📡 API Data only |
| `upload_only` | 📁 Upload Report only |
| `sell_side` | 📈 Sell Side + 🎯 Audiences & Deals Pipeline |

Sidebar order is always: logo → API Data → Upload Report → Sell Side → Audiences & Deals Pipeline. Sections not included in the active tier's `visible` list are hidden entirely.

## Data Sources

### Supported DSP Exports

| DSP | Format | Notes |
|-----|--------|-------|
| DV360 (Display & Video 360) | CSV | Standard campaign/line item exports |
| The Trade Desk (TTD) | CSV | Campaign/ad group reports |
| Generic programmatic | CSV, TSV, XLSX, XLS | Any tabular export with recognisable columns |

### Column Auto-Detection

The app normalises column names on upload. It accepts the following naming variants and maps them to internal standard names:

| Internal name | Accepted column names |
|---------------|-----------------------|
| `campaign` | Campaign, Campaign Name, Brand Name, Insertion Order, Advertiser, Brand |
| `line_item` | Line Item, Line Item Name, Ad Group, Ad Group Name, Creative |
| `impressions` | Impressions, Served Impressions, Total Impressions |
| `clicks` | Clicks, Total Clicks, Link Clicks |
| `spend_usd` | Spend, Spend (USD), Media Cost, Revenue (USD), Billed Spend, Cost |
| `date` | Date, Day, Week, Month |
| `device_type` | Device Type, Device, Device Category |
| `environment` | Environment, Environment Type, Inventory Type, Supply Type |
| `conversions` | Conversions, Total Conversions, Post-Click Conversions |

CTR and CPM are always **recalculated from raw impressions/clicks/spend** — pre-computed values from the DSP are never used directly.
